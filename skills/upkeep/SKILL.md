# Upkeep

Prefer the `upkeep` MCP server (`upkeep mcp`) or Code Mode namespace; fall back to the CLI with `--json`.

- `upkeep status --json` lists the jobs Upkeep runs.
- `upkeep agent tools --json` prints every operation with how an agent may use it.
